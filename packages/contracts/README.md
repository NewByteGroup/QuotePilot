# contracts

Source of truth for shapes shared between `core-api`, `ai-engine` and `web`.

## What belongs here

- OpenAPI 3.0.3 specs and JSON Schema files (3.0.3, not 3.1 — see ADR-002).
- Codegen configuration for Go, Pydantic and TypeScript.

## What must never go here

- Hand-edited generated code.
- Changes made without Pedro's approval (see `AGENTS.md`).

## Layout

- `openapi/core-api.yaml`: request edge `core-api` implements (auth, `/me`); generates the Go
  server interface via oapi-codegen (`apps/core-api/oapi-codegen.yaml`).
- `openapi/web-api.yaml`: endpoints the web app consumes today (inbox, quotes, rates, identity,
  connectors, repairs, user preferences). It drives the TypeScript client and the MSW mock in
  `apps/web`; its endpoints are to be folded into `core-api.yaml` (as 3.0.3) as `core-api`
  implements them.
- `generated/ts/web-api.ts`: TypeScript types generated by `openapi-typescript` from
  `web-api.yaml`, exported as `@quotepilot/contracts/web-api`.

## Commands

- `make generate` (here) or `make contracts-drift` (repo root): regenerate Go and TypeScript and
  fail on any diff. The Go step needs the Go toolchain.
- `pnpm --filter @quotepilot/contracts generate`: regenerate only the TypeScript types.
- `pnpm --filter @quotepilot/contracts lint`: lint `web-api.yaml` (Redocly).
