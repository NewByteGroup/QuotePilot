# contracts

Source of truth for shapes shared between `core-api`, `ai-engine` and `web`.

## What belongs here

- OpenAPI 3.1 specs and JSON Schema files.
- Codegen configuration for Go, Pydantic and TypeScript.

## What must never go here

- Hand-edited generated code.
- Changes made without Pedro's approval (see `AGENTS.md`).

## Layout

- `openapi/core-api.yaml`: HTTP API of `core-api`, consumed by `web`.
- `generated/ts/`: TypeScript types generated by `openapi-typescript`, exported as `@quotepilot/contracts/core-api`.

## Commands

- `pnpm --filter @quotepilot/contracts generate`: regenerate the TypeScript types.
- `pnpm --filter @quotepilot/contracts lint`: lint the OpenAPI spec (Redocly).
- `make contracts-drift` (from the repo root): regenerate and fail on any diff (TypeScript only for now; Go and Pydantic are still stubs).
